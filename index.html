Prosjekter

Hva jeg selv hadde ansvar for, og hvor du finner koden.

Skapertorget

Eksamensprosjekt i APP2000, gruppe på 6 studenter

En nettbasert markedsplass for kjøp og salg av brukte og håndlagde klær, med chat mellom kjøper og selger, tilbakemeldinger, hjelpesenter og betaling via Stripe.

Min del: Jeg hadde ansvar for meldingsfunksjonen. Jeg laget datamodellen og REST API-et i Django REST Framework, slik at kjøper og selger kan sende, svare på og slette meldinger om et produkt.

  • Django
  • Django REST Framework
  • SQLite
  • JavaScript
  • Git

Endepunktene jeg laget

GET/api/chat/messages?chat_id={id}

POST/api/chat/messages/send
Kjøper sender en ny melding
POST/api/chat/messages/selger-svar
Selger svarer kjøperen
DELETE/api/chat/messages/delete/{id}
